# Ubuntu Server – Linux Administration & Networking Lab

## Project Overview

A hands-on Ubuntu Server lab focused on Linux administration, network configuration, SSH access, connectivity testing, and troubleshooting

The lab was completed in a virtualised environment to develop practical experience managing a Linux server and configuring network connectivity

## Objectives

- Install and configure Ubuntu Server
- Configure network interfaces
- Configure a static IP address
- Configure virtual networking
- Test network connectivity
- Install and configure OpenSSH
- Connect to the server using SSH
- Troubleshoot network and connectivity issues
- Document the configuration and troubleshooting process

## Technologies & Tools

- Ubuntu Server
- VirtualBox
- Netplan
- OpenSSH
- Linux Command Line
- NAT Networking
- Host-only Networking

## Networking Configuration

The lab used VirtualBox networking to provide connectivity between the Ubuntu Server and the lab environment

Network configuration was managed using Netplan

The server was configured with a static IP address to provide predictable connectivity within the lab environment

## SSH Configuration

OpenSSH was configured to allow remote administration of the Ubuntu Server

SSH connectivity was tested from the client environment to verify that the server was accessible remotely

## Testing & Troubleshooting

Network connectivity and SSH access were tested during the lab

Troubleshooting included checking network configuration, verifying IP addressing, testing connectivity, and investigating SSH access problems

## Key Skills Demonstrated

- Linux Server Administration
- Network Configuration
- TCP/IP Fundamentals
- Static IP Configuration
- Netplan
- SSH
- Virtual Networking
- Network Troubleshooting
- Command-Line Administration
- Technical Documentation

## What I Learned

This lab provided practical experience configuring and administering an Ubuntu Server in a virtualised environment

I learned how Linux network configuration works, how Netplan is used to manage network interfaces, and how static IP addressing can be configured

The lab also reinforced the importance of troubleshooting network connectivity systematically by checking configuration, addressing, interfaces, and connectivity before moving on to higher level services such as SSH
